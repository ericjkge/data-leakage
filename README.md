# data-leakage

A CS2881 mini-project reproducing Table 1 of [Retracing the Past: LLMs Emit Training Data When They Get Lost](https://arxiv.org/abs/2511.05518) (Ko et al., EMNLP 2025). The paper introduces Confusion-Inducing Attacks (CIA), which use a GCG-style search to craft input snippets that maximize the model's token-level prediction entropy, steering it into a confused state where it is more likely to regurgitate memorized training data. We compare CIA against the paper's untargeted extraction baselines (RA, EA, RWA, RSA) on open models whose pretraining corpora are indexed by [infini-gram](https://infini-gram.io): Pythia-1.4B and Pythia-6.9B (The Pile) and OLMo-7B-0424 (Dolma v1.7). Generations are checked against the corpus and scored as 50-token matches allowing 0, 5, or 10 token mismatches (VM@50, M5@50, M10@50).
